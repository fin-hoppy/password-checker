# Password Strength Checker

[English](README.md) | [日本語](README.ja.md)

## 概要

Password Strength Checkerは、独自のルールベースの採点方式を用いてパスワードの強度を評価するPython製のコマンドラインアプリケーションです。

パスワードの長さ、文字の多様性、同一文字の連続、繰り返しパターンなどを分析し、0～100点の範囲で評価します。

本プログラムは学習を目的として開発されており、実際のパスワードの安全性を保証するものではありません。

## 主な機能

- 0～100点によるパスワード強度評価
- 印字可能なASCII文字の入力検証
- 異なる文字数による評価
- 異なる文字の割合による評価
- パスワード長による評価
- 同一文字の連続検出
- 繰り返し部分文字列の検出
- パスワード長に応じた得点制限
- 対話型コマンドラインインターフェース
- 単体テスト・統合テスト

## アーキテクチャ

保守性とテスト容易性を高めるため、ユーザーとの入出力、入力検証、採点処理をそれぞれ独立したモジュールに分離しています。

| ファイル | 役割 |
|---|---|
| password_checker.py | エントリーポイント・各モジュールの読み込み |
| cli.py | 入出力・メニュー制御 |
| validation.py | 入力検証・エラー情報管理 |
| scoring.py | 採点処理・パターン検出 |
| test_password_checker.py | 単体テスト・統合テスト |

## 採点アルゴリズム

以下の評価項目から総合点を計算します。

| 評価項目 | 最大得点 |
|---|---:|
| 異なる文字の数 | 45点 |
| 異なる文字の割合 | 20点 |
| パスワードの長さ | 20点 |
| 繰り返しパターンの評価 | 15点 |
| 合計 | 100点 |

また、同一文字が連続する場合は最大30点の減点を行います。

### 長さによる得点制限

| パスワードの長さ | 最大得点 |
|---|---:|
| 1～4文字 | 5点 |
| 5～7文字 | 30点 |
| 8～14文字 | 60点 |
| 15文字以上 | 100点 |

4文字以下の場合は、パスワード長による加点と同一文字の連続による減点のみを適用します。

### 繰り返しパターン

以下の条件を満たす部分文字列を検出します。

- 2文字以上で構成されていること。
- 異なる文字を2種類以上含むこと。
- 重ならない位置に複数回出現すること。
- 大文字と小文字を区別すること。

複数のパターンが検出された場合は、最も低いパターン得点を採用します。

## 入力検証

以下の入力を拒否します。

- 空文字列
- 半角スペースのみで構成された文字列
- ASCII以外の文字を含む文字列
- 印字可能ASCII文字（32～126）の範囲外の文字

複数の入力エラーが存在する場合は、エラー情報をまとめて返します。

## 制限事項

- 独自の採点方式であり、実際のパスワードの安全性を保証するものではありません。
- パスワードの解読に必要な時間は推定しません。
- 頻出パスワードや漏洩済みパスワードの検出には対応していません。
- 予測しやすい規則的な文字列でも高得点になる場合があります。
- Unicode文字には対応していません。
- 入力したパスワードはターミナル上に表示されます。
- 長い文字列では繰り返しパターン探索の処理負荷が増加する可能性があります。
- 明示的な最大入力長は設定されていません。
